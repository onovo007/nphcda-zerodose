# Branding assets

Drop two images here and the app will use them automatically (it falls back to a gradient and
a text logo if they are absent):

- `nphcda_logo.png` - the NPHCDA agency logo. Shown in the sidebar header.
- `hero.jpg` - a field immunization photo. Used as the Home-page hero background, under a
  navy-to-green gradient overlay.

Use an NPHCDA-owned or properly licensed photo for `hero.jpg`. Avoid embedding copyrighted
press/stock images in a publicly deployed app.

Recommended sizes: logo about 400 px wide (transparent PNG); hero about 1600 x 900 px JPEG.
